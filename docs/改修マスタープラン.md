## 1. 全体方針
- §13 の順序(集計/CSV → DB → 記録 → ダッシュボード → 履歴 → 設定 → PWA)で初版を作り、Android 実機の手動確認(§10)を経て `main` へ公開する。
- 公開(= `main` への push)は都度ユーザーの許可を得る(`CLAUDE.md` §14.5)。
- スコープ外(§12)には着手しない。
